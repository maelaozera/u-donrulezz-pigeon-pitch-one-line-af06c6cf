A city pigeon pitches investors its startup, PigeonPay: tourists pay per
poop on your statue, the pigeon takes 30% — recurring revenue, zero CAC, and
users who never leave the park, because the crumbs are here. One line, 175
characters, in the pigeon's own voice.

## Run

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` (validated: 1–200 characters,
exactly one line).
